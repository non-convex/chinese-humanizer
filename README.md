# 去 AI 味 · chinese-humanizer

一个用于中文写作和改写的技能，让回答平实、具体、易懂，减少套话、刻意强调、抽象名词堆叠和机械排版。

技能保留了原始写作规范的八部分规则和五组示例。改写时保留原文的事实、立场、结论和必要条件；只要求调整格式时，不改措辞。

## 文件

- [SKILL.md](SKILL.md) 包含技能名称、适用场景、使用方式和八部分写作规则。
- [references/examples.md](references/examples.md) 包含日常交流、概念解释、金融机制和技术回答的写法对照。

## 调用示例

在已加载此技能的环境中，可以这样请求：

```text
使用 $chinese-humanizer 改写下面这段话，保留事实和原意，让表达自然、具体、容易看懂。

在这里粘贴原文。
```

也可以用它直接撰写中文回答：

```text
使用 $chinese-humanizer，向第一次接触这个话题的人解释数据库索引。
```
